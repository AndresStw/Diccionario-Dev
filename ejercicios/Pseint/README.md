## 🎯 ¿Por qué resolver ejercicios?

Algo interesante de programar es que, cuando terminas un ejercicio, empiezas a pensar:

- ¿Se podría resolver de una forma más sencilla?
- ¿Qué pasaría si el usuario introduce otro dato?
- ¿Puedo mejorar la organización del algoritmo?
- ¿Qué otros ejercicios podría crear a partir de este?

¡Y de repente llevas media hora pensando cómo mejorar un programa que solamente suma dos números! 😂

Por eso recomiendo practicar pseudocódigo todos los días, aunque sean 30 minutos. La constancia ayuda a mantener fresca la lógica y a desarrollar el hábito de resolver problemas.

## 📚 ¿Cómo utilizar este material?

Mi recomendación es que utilices estos ejercicios como **guía de estudio y referencia**, no como una lista de respuestas para copiar.

1. Lee el enunciado.
2. Intenta resolverlo por tu cuenta.
3. Dibuja o analiza el diagrama de flujo.
4. Escribe tu algoritmo en PSeInt.
5. Ejecuta el programa y comprueba los resultados.
6. Compara tu solución con la que encontrarás aquí y piensa cómo podrías mejorarla.

## ⚠️ Reglas de práctica

- **Intenta resolver los ejercicios por tu cuenta antes de consultar las soluciones.**
- **No utilices inteligencia artificial para resolver los problemas.** El objetivo es entrenar tu propia lógica.
- Puedes consultar documentación y apuntes para comprender las instrucciones.
- Si encuentras un error, intenta identificarlo y corregirlo antes de buscar ayuda.
- No te preocupes si tu solución es diferente: puede haber varias formas válidas de resolver un mismo problema.

La idea no es terminar rápido, sino comprender lo que estás haciendo.
