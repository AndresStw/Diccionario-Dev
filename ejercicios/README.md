## 📏 Reglas para resolver ejercicios

Antes de mirar cualquier solución, lee esto:

1. **Intenta resolverlo por tu cuenta primero.** Aunque te tome una hora. Ese tiempo es donde aprendes.
2. **No uses IA para generar soluciones completas.** Puedes preguntarle cosas puntuales, pero la lógica es tuya.
3. **Ejecuta el código.** No basta con "creo que funciona".
4. **Prueba con datos raros.** ¿Qué pasa si el usuario ingresa 0? ¿O un texto en vez de un número?
5. **Compara soluciones.** La tuya puede ser distinta a la mía y estar bien. Puede haber mil formas de resolver lo mismo.

> 🎯 **Consejo:** no se trata de terminar rápido. Se trata de entender **por qué** funciona.
