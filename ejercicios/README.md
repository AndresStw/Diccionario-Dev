# Ejercicios

Este directorio está dedicado a ejercicios prácticos que pueden resolverse individualmente o en grupo.

## Categorías

### Básicos

- Suma de dos números
- Promedio de notas
- Edad mayor o menor
- Número par o impar
- Arreglo de nombres

### Intermedios

- Calculadora simple
- Registro de estudiantes
- Clase Persona con atributos
- Clase Producto con precio y cantidad
- Clase CuentaBancaria

### Proyectos pequeños

- Lista de tareas
- Sistema de notas
- Mini agenda
- Juego de adivinanza

## Recomendación

Cada ejercicio debe incluir:

- enunciado
- solución propuesta
- explicación breve
- ejemplos de salida
