# 🧠 10 ejercicios de pseudocódigo en PSeInt

**Nivel:** Principiante → Principiante avanzado  
**Objetivo:** Practicar variables, entradas, procesos, salidas, condicionales y ciclos.

¡Bienvenido a tus primeros retos de lógica de programación! 🚀

La idea no es copiar y pegar código, sino aprender a pensar como programador. Lee cada enunciado, identifica los datos que necesitas y construye tu propio algoritmo.

## 📚 Lista de ejercicios

### 🟢 Nivel 1: Operaciones básicas

#### 1. Suma de dos números

**Dificultad:** Fácil

Solicita dos números al usuario, calcula su suma y muestra el resultado.

- **Ejemplo:** `8 + 5 = 13`
- **Practicas:** Variables, `Leer`, `Escribir` y operaciones aritméticas.

#### 2. Promedio de tres notas

**Dificultad:** Fácil

Solicita tres calificaciones, calcula el promedio y muéstralo.

- **Ejemplo:** Notas `4`, `3` y `5` → promedio `4`.
- **Practicas:** Variables reales, división y operaciones matemáticas.

#### 3. Conversor de centímetros a pulgadas

**Dificultad:** Fácil

Solicita una medida en centímetros y conviértela a pulgadas.

- **Fórmula:** `pulgadas = centímetros / 2.54`
- **Ejemplo:** `10 cm` → aproximadamente `3.94 pulgadas`.
- **Practicas:** Fórmulas, división y números decimales.

### 🟡 Nivel 2: Condicionales

#### 4. ¿Eres mayor de edad?

**Dificultad:** Fácil

Solicita la edad de una persona y determina si es mayor o menor de edad.

- **Regla:** A partir de los 18 años se considera mayor de edad.
- **Practicas:** `Si`, `SiNo` y operadores de comparación.

#### 5. Número par o impar

**Dificultad:** Fácil

Solicita un número entero e indica si es par o impar.

- **Pista:** Utiliza `MOD` para calcular el residuo de dividir entre 2.
- **Practicas:** Condicionales, operaciones aritméticas y módulo.

#### 6. El número mayor

**Dificultad:** Intermedia

Solicita tres números y determina cuál es el mayor. Si dos o más números son iguales, tu algoritmo también debe contemplarlo.

- **Pista:** Piensa qué sucede cuando los tres números son iguales.
- **Practicas:** Condiciones múltiples, operadores `Y` y comparaciones.

#### 7. ¿Me levanto o sigo durmiendo? 😂

**Dificultad:** Intermedia

Pregunta si tienes clases hoy (`S/N`) y si ya son las 6:00 a. m. Decide si debes levantarte o puedes seguir durmiendo.

- **Pista:** Puedes utilizar condicionales anidadas.
- **Practicas:** Condicionales anidadas y operadores lógicos.

_El algoritmo más importante de la vida estudiantil._

### 🔵 Nivel 3: Ciclos y acumuladores

#### 8. Tabla de multiplicar

**Dificultad:** Intermedia

Solicita un número y muestra su tabla de multiplicar del 1 al 10.

- **Ejemplo:** Para el número `3`, muestra desde `3 × 1 = 3` hasta `3 × 10 = 30`.
- **Practicas:** Ciclo `Para`, contadores y multiplicaciones.

#### 9. Ahorro semanal

**Dificultad:** Intermedia

Pregunta cuánto dinero ahorras cada semana y durante cuántas semanas. Calcula el ahorro total.

- **Reto extra:** Si el ahorro cambia cada semana, solicita cada cantidad y acumúlala.
- **Practicas:** Ciclos, acumuladores y variables.

#### 10. ¡Adivina el número!

**Dificultad:** Reto final 🏆

Define un número secreto y pide al usuario que intente adivinarlo. Indica si su respuesta es demasiado alta, demasiado baja o correcta. Repite hasta que acierte.

- **Pista:** Puedes utilizar los ciclos `Mientras` o `Repetir`.
- **Practicas:** Ciclos, condicionales y validación.

## 🧩 Plantilla para resolver cada ejercicio

Intenta organizar tus algoritmos con los cuatro elementos que estás estudiando:

```pseint
Algoritmo NombreDelEjercicio

    // Datos
    // Declarar variables

    // Entradas
    // Solicitar información al usuario

    // Procesos
    // Resolver el problema

    // Salidas
    // Mostrar resultados

FinAlgoritmo
```

## 📏 Reglas del reto

1. **Intenta resolver cada ejercicio por tu cuenta** antes de buscar una solución.
2. Utiliza comentarios para explicar las partes importantes de tu algoritmo.
3. Prueba diferentes datos para comprobar que tu solución funciona.
4. Si te equivocas, revisa tu lógica antes de reescribir todo el código.
5. Como reto personal, intenta resolverlos **sin utilizar IA para generar las soluciones**. Puedes consultar documentación y tus apuntes para aprender.

## 🎯 ¿Qué aprenderás?

Al completar los diez ejercicios, habrás practicado los fundamentos necesarios para comenzar a construir algoritmos más complejos y trasladar tu lógica a lenguajes como Java, JavaScript o C#.

**Recuerda:** no se trata de escribir mucho código, sino de aprender a resolver problemas paso a paso.

_Un programador no nace sabiendo; se equivoca, depura y vuelve a intentarlo. ¡A practicar!_ 💻
