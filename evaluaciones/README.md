## 📋 Reglas generales

1. **Intenta resolverlas sin mirar las soluciones.** Sino, no sirve de nada. 😅
2. **No uses IA para responder.** El objetivo es medir **tu** conocimiento, no el de la máquina.
3. **Puedes consultar documentación** si no recuerdas una sintaxis exacta. Eso no es hacer trampa, es ser realista.
4. **Tiempo límite:** cada evaluación indica una duración estimada. Si tardas más, no pasa nada, pero intenta respetarla.
5. **Auto-calificación:** cada evaluación trae su propia hoja de respuestas. Sé honesto al corregirte.
