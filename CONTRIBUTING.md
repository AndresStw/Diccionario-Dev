# Guía de contribución

Gracias por querer aportar a este repositorio. Este espacio está pensado para crecer en comunidad, por eso valoramos contenido útil, claro y ordenado.

## ¿Qué tipo de contribución aceptamos?

Puedes colaborar con:
- correcciones de apuntes
- nuevos ejemplos de sintaxis
- ejercicios para practicar
- mini proyectos
- mejoras en documentación
- comentarios y sugerencias

## Estructura recomendada

Usa la carpeta adecuada según tu aporte:

- `apuntes/` → conceptos, referencias, ejemplos rápidos
- `ejercicios/` → ejercicios por tema o nivel
- `proyectos/` → mini proyectos de práctica
- `comunidad/` → guías, normas y recursos comunitarios

## Flujo recomendado

1. Haz un fork o clona el repositorio.
2. Crea una rama nueva.
3. Agrega o modifica archivos en la categoría correcta.
4. Verifica que el contenido esté bien redactado y ordenado.
5. Abre un Pull Request con una descripción clara.

## Convenciones para ramas

Usa nombres descriptivos, por ejemplo:
- `docs/apuntes-java`
- `feature/ejercicio-condicionales`
- `project/calculadora-basica`

## Convenciones para commits

Mantén mensajes claros y breves, por ejemplo:
- `Agregar apuntes de variables en Java`
- `Crear ejercicios de condicionales`
- `Documentar guía de colaboración`

## Reglas básicas

- Escribe en español o en el idioma que uses en el canal.
- Mantén un estilo claro y didáctico.
- No subas contenido duplicado o sin contexto.
- Si agregas código, procura que sea legible y funcional.
- Si aportas soluciones, explica la idea general.

## Antes de abrir un PR

Revisa lo siguiente:
- ¿El contenido está en la carpeta correcta?
- ¿Tiene un nombre claro?
- ¿Está bien documentado?
- ¿La propuesta ayuda a la comunidad?

## Dudas o sugerencias

Si tienes una duda, idea o propuesta, puedes abrir un issue o usar GitHub Discussions.

Gracias por formar parte de la comunidad.
