# Código de conducta

Queremos que este repositorio sea un espacio respetuoso, amable y útil para todas las personas.

## Nuestra expectativa

- Respetar a todas las personas
- Mantener un ambiente de aprendizaje positivo
- Dar feedback de manera constructiva
- Apreciar la diversidad de experiencias y niveles

## Lo que no aceptamos

- insultos, comentarios ofensivos o discriminación
- acoso o comportamiento intimidante
- spam o contenido irrelevante
- abuso de issues, discusiones o pull requests

## Reportes

Si una persona rompe estas normas, puedes reportarlo con un mensaje privado al administrador del repositorio o mediante canales de contacto habilitados por el proyecto.

## Resultado

Nos reservamos el derecho de moderar, cerrar o eliminar contenido que afecte el ambiente de la comunidad.

El objetivo principal es aprender y crecer juntos con respeto.
