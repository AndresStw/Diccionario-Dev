# 🧠 Fundamentos de programación

Antes de escribir código en un lenguaje real, hay que entender **cómo se piensa como programador**. Esta carpeta reúne todo eso.

Aquí no hay sintaxis de Java ni de C#. Aquí hay **lógica pura**: cómo funcionan los ciclos, cómo se detectan errores, cómo se organiza un algoritmo con diagramas.

---

## 📚 Contenido de esta carpeta

### 🔁 [Ciclo `Para`](./ciclo-para.md)

**El primer ciclo que todos aprendemos.**

Cuándo usarlo, cómo funciona, y por qué es el más simple de los tres. Con ejemplos clásicos como sumar del 1 al 10.

> 🎯 Ideal si te preguntas: _"¿Cómo repito algo N veces?"_, _"¿Cómo funciona un acumulador?"_

### 🔄 [Ciclos `Mientras` y `Repetir`](./ciclos-mientras-repetir.md)

**Los ciclos cuando no sabes cuántas veces repetir.**

La diferencia clave entre comprobar la condición **antes** o **después**. Con el ejemplo práctico del juego "Adivina el número".

> 🎯 Ideal si te preguntas: _"¿Cuándo uso `Mientras` y cuándo `Repetir`?"_, _"¿Cómo evito un ciclo infinito?"_

### 📊 [Diagramas de flujo](./diagramas-de-flujo.md)

**La lógica antes del código.**

Cómo representar un algoritmo con símbolos antes de escribir una sola línea. Perfecto para planificar y para clases.

> 🎯 Ideal si te preguntas: _"¿Cómo planifico un algoritmo?"_, _"¿Qué significa ese rombo?"_, _"¿Necesito dibujar antes de programar?"_

### 🐛 [Cómo detectar errores](./como-detectar-errores.md)

**Manual de supervivencia del programador.**

Qué hacer cuando tu programa no responde, cómo escapar de un ciclo infinito, cómo leer un mensaje de error sin llorar, y por qué **guarda tus avances** es el mejor consejo del mundo.

> 🎯 Ideal si te preguntas: _"Mi programa se congeló, ¿qué hago?"_, _"¿Cómo depuro mi código?"_, _"¿Por qué no compila?"_

↓

---

## 🎯 ¿Por qué son tan importantes?

Porque son **universales**. Aprendes el ciclo `Para` en PSeInt y lo aplicas en Java, C#, JavaScript, Python y cualquier lenguaje. Solo cambia la sintaxis.

**La lógica es lo que se queda. La sintaxis se olvida.**
