# 🛠️ Setup y herramientas del programador

Todo lo que necesitas para preparar tu entorno de desarrollo sin volverte loco. 🧰

Porque programar está bien, pero antes hay que pelear con instaladores, variables de entorno y extensiones que a veces parecen querer hacerte la vida imposible. 😂

---

## 📚 Contenido de esta carpeta

### 💻 [El Setup del Programador](./setup-del-programador.md)

**Guía completa de herramientas.**

Qué instalar, en qué orden y por qué. Editores, IDEs, JDK, .NET SDK, Git, GitHub, variables de entorno, y las herramientas que realmente valen la pena tener.

Cubre:

- VS Code vs Visual Studio vs IntelliJ IDEA
- Java (JDK, `JAVA_HOME`, comprobaciones)
- Desarrollo web (HTML, CSS, JS, Node.js)
- C# y .NET
- Variables de entorno en Windows
- Git y GitHub desde cero

> 🎯 Ideal si te preguntas: _"¿Qué instalo primero?"_, _"¿Por qué mi terminal no reconoce `java`?"_, _"¿Qué es una variable de entorno?"_

### 🙏 [La Santa Trinidad de VS Code](./santa-trinidad-vscode.md)

**Extensiones imprescindibles.**

Las tres extensiones que recomiendo y las que van de apoyo. Todo con mi veredicto personal y sin exagerar con "instala 50 extensiones porque sí".

> 🎯 Ideal si te preguntas: _"¿Qué extensiones instalo en VS Code?"_, _"¿Qué hace Prettier?"_, _"¿Cómo mejoro la apariencia del editor?"_

---

## ✅ Checklist rápido

Antes de empezar tu primer proyecto, asegúrate de tener:

- [ ] Un editor o IDE instalado
- [ ] El SDK o lenguaje que vas a usar
- [ ] Git instalado y configurado
- [ ] Comprobado que todo funciona desde la terminal
- [ ] Las extensiones necesarias para tu lenguaje
