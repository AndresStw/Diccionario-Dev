# 📚 Temas de práctica

Bienvenido a la ruta de aprendizaje de **Diccionario-Dev**. 🚀

Aquí encontrarás los temas que recomendamos estudiar y practicar para avanzar desde los fundamentos de la programación hasta la creación de proyectos más completos.

No necesitas aprenderlo todo en un día. Lo importante es comprender cada concepto, practicarlo y aprender de los errores. Porque sí, ese punto y coma que falta también forma parte de tu formación como programador. 😂

## 🟢 Principiante

**Objetivo:** comprender la lógica básica de programación y aprender a resolver problemas sencillos.

- [ ] Variables y tipos de datos.
- [ ] Entrada y salida de datos.
- [ ] Operadores aritméticos y lógicos.
- [ ] Condicionales (`if`, `else`, `switch`).
- [ ] Ciclos (`for`, `while`, `do while`).
- [ ] Arreglos y colecciones básicas.
- [ ] Algoritmos y pseudocódigo.
- [ ] Comentarios y documentación del código.

**💡 Ideas para practicar:**

- Sumar dos números.
- Calcular el promedio de varias notas.
- Convertir centímetros a pulgadas.
- Determinar si una persona es mayor de edad.
- Crear un algoritmo para decidir si levantarse o seguir durmiendo según la alarma y si tienes clases. 😴

## 🟡 Intermedio

**Objetivo:** organizar mejor el código, reutilizar soluciones y comprender los fundamentos de la programación orientada a objetos.

- [ ] Funciones y métodos.
- [ ] Parámetros y valores de retorno.
- [ ] Clases y objetos.
- [ ] Constructores.
- [ ] Encapsulamiento.
- [ ] Herencia.
- [ ] Polimorfismo.
- [ ] Manejo de errores y excepciones.
- [ ] Organización del código en archivos y módulos.
- [ ] Colecciones y estructuras de datos básicas.

**💡 Ideas para practicar:**

- Crear una calculadora con funciones.
- Desarrollar un sistema sencillo de estudiantes y notas.
- Crear clases para representar personajes de un videojuego.
- Validar entradas para evitar que el programa falle ante datos incorrectos.
- Reorganizar un programa grande en varios archivos.

## 🔴 Avanzado

**Objetivo:** desarrollar aplicaciones más completas, gestionar información y aplicar buenas prácticas de desarrollo.

- [ ] Proyectos con estructura modular.
- [ ] Operaciones CRUD (crear, consultar, actualizar y eliminar).
- [ ] Consumo y creación de APIs sencillas.
- [ ] Persistencia de datos.
- [ ] Conexión con bases de datos.
- [ ] Validación de datos y manejo de errores.
- [ ] Buenas prácticas de programación.
- [ ] Control de versiones con Git y GitHub.
- [ ] Pruebas de software.
- [ ] Documentación de proyectos.

**💡 Ideas para practicar:**

- Crear un sistema de gestión de estudiantes.
- Desarrollar una lista de tareas que guarde los datos.
- Construir una API sencilla para administrar productos.
- Crear una aplicación que consulte y almacene información en una base de datos.
- Trabajar en un proyecto colaborativo utilizando ramas y Pull Requests.

> 📌 Estos niveles son orientativos. Algunos temas pueden estudiarse en distinto orden dependiendo del lenguaje y de los conocimientos previos.

## 🧠 Recomendaciones para practicar

### 1. Practica un ejercicio al día

No necesitas construir el próximo Minecraft en una tarde. 😂

Empieza con ejercicios pequeños, comprende la lógica y aumenta la dificultad progresivamente.

### 2. Compara la misma lógica en diferentes lenguajes

Resuelve un mismo problema en Java, JavaScript y C#.

Por ejemplo, puedes crear un programa que sume dos números en los tres lenguajes y comparar cómo se declaran las variables, cómo se reciben los datos y cómo se muestra el resultado.

**Nota:** iremos incorporando más lenguajes con el tiempo, según crezca la comunidad.

### 3. Documenta tus soluciones

Explica qué hace tu programa, qué datos utiliza y cómo funciona.

Una solución bien documentada puede ayudar a otra persona a comprender un concepto que al principio parecía complicado.

### 4. Comenta tu código estratégicamente

Cuando sea apropiado, organiza tus algoritmos utilizando estas secciones:

- **Datos:** variables y estructuras necesarias.
- **Entradas:** información que recibe el programa.
- **Procesos:** operaciones, cálculos y decisiones.
- **Salidas:** resultados que muestra el programa.

Esta estructura es especialmente útil al comenzar con algoritmos y pseudocódigo. A medida que avances, aprenderás a documentar de una forma más adaptada a cada proyecto.

### 5. Comparte tus dudas en Discussions

¿Encontraste un error? ¿No entiendes una condición? ¿Tienes una forma diferente de resolver un ejercicio?

Comparte tu duda en **GitHub Discussions**, si está habilitado en el repositorio. Explica qué intentaste, qué esperabas obtener y qué resultado conseguiste.

Recuerda: preguntar no es una señal de debilidad. Quedarse tres horas mirando un error sin pedir ayuda tampoco te da puntos extra. 💀

### 6. Incluye la autoría de tus aportes

Cuando crees un ejercicio, una guía o una solución para este repositorio, identifica al autor y añade información útil para que otros puedan consultarte.

Por ejemplo:

```text
Autor: AndresStw
Lenguaje: C#
Tema: Condicionales
Descripción: Ejercicio para practicar estructuras Si/Sino.
```

Si contribuyes al repositorio, puedes utilizar tu usuario de GitHub como referencia. Así otras personas podrán encontrar tu perfil y conocer tus aportes.

**Importante:** atribuye correctamente las fuentes y los colaboradores cuando reutilices o adaptes material de otras personas.
