# 📚 Apuntes y Referencias Rápidas

Bienvenido al corazón de **Diccionario-Dev**. Aquí vive todo el conocimiento que voy recopilando mientras aprendo a programar. 🧠

No esperes un manual aburrido. Esto es más bien un cuaderno de campo: apuntes escritos desde la trinchera, con humor, errores y aprendizajes reales.

> 💡 **¿Cómo usar esta carpeta?** Empieza por los **fundamentos** si vienes desde cero. Si ya tienes bases, salta directo al lenguaje que te interese.

## 🎯 Objetivo de esta sección

- **Explicar** conceptos desde cero, sin asumir que ya sabes programar.
- **Comparar** la misma lógica entre distintos lenguajes (PSeInt ↔ Java ↔ C#).
- **Servir** como referencia rápida cuando estés resolviendo ejercicios.

> 💡 **Recomendación:** usa esta sección como consulta previa antes de resolver ejercicios. Si algo no te queda claro en un lenguaje, seguro está explicado desde otra perspectiva en otro apunte.
