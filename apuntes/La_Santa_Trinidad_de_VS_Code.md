### 🎨 1. Material Icon Theme

**El estilista oficial de tus archivos.**

Añade iconos a los archivos y carpetas de VS Code para que puedas reconocerlos visualmente con mayor facilidad.

- Identifica archivos según su tipo.
- Mejora la apariencia del explorador.
- Facilita navegar por proyectos con muchas carpetas.

**Mi veredicto:** porque un archivo `.json` merece tener identidad propia y no vivir como un documento anónimo. 😂

### 🧹 2. Prettier — Code Formatter

**El peluquero del código.**

Prettier es un formateador que organiza automáticamente el código compatible con sus reglas.

- Mantiene una indentación consistente.
- Organiza espacios y saltos de línea.
- Reduce las discusiones sobre estilos de escritura.
- Puede configurarse para formatear al guardar.

**Mi veredicto:** tu lógica puede estar en crisis, pero al menos tus espacios estarán en orden. 💈

> Nota: Prettier no corrige errores de lógica ni garantiza que tu programa funcione. Solo se encarga del formato.

### 🌈 3. Color Highlight

**Los colores dejan de ser jeroglíficos.**

Resalta visualmente valores de color reconocidos en el código, como los códigos HEX o RGB compatibles.

```css
body {
  background-color: #121212;
  color: #ffffff;
}

button {
  background-color: #ffd700;
}
```

Así puedes identificar los colores directamente desde el editor.

**Mi veredicto:** escribir `#FFD700` y esperar que tu cerebro recuerde el tono exacto es una prueba que nadie pidió. 😂

## 🚀 Cómo instalar las extensiones

1. Abre Visual Studio Code.
2. Presiona `Ctrl + Shift + X`.
3. Escribe el nombre de la extensión.
4. Comprueba que sea la correcta.
5. Haz clic en **Instalar**.

Repite el proceso con las extensiones que quieras utilizar.

### ⚙️ Consejo extra: activa el formato al guardar

Si utilizas Prettier, puedes habilitar esta opción en la configuración de VS Code:

1. Abre la configuración con `Ctrl + ,`.
2. Busca `Format On Save`.
3. Activa **Editor: Format On Save**.
4. Si hace falta, selecciona Prettier como formateador predeterminado para el lenguaje que estés usando.

Ten presente que algunas extensiones de otros lenguajes pueden requerir configuraciones adicionales.
