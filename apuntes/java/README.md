## 📚 Contenido de esta carpeta

### 📘 [El universo Java](./apuntes.md)

**Filosofía, contexto y mentalidad.**

Si vienes de PSeInt y quieres entender **por qué** Java es como es, empieza aquí. Hablamos de la JVM, el JDK, la organización de proyectos, convenciones, y la mentalidad que necesitas para no frustrarte.

> 🎯 Ideal si te preguntas: _"¿Por qué Java escribe tanto?"_, _"¿Qué es la JVM?"_, _"¿Por dónde empiezo?"_

### 📗 [Sintaxis de Java](./sintaxis.md)

**Cómo se escribe Java, línea por línea.**

Aquí desmenuzamos `public static void main`, `System.out.println`, variables, tipos, entradas, salidas, condicionales y ciclos. Todo comparado con PSeInt para que la transición sea más suave.

> 🎯 Ideal si te preguntas: _"¿Qué significa `static`?"_, _"¿Cómo leo datos del usuario?"_, _"¿Cómo se declara una variable?"_

### ⚡ [Truquitos de Java](./truquitos.md)

**Atajos, cheatsheet y herramientas del IDE.**

Combinaciones de teclado, plantillas de código (`psvm`, `sout`), atajos de IntelliJ IDEA y VS Code. Todo para escribir más rápido sin perder calidad.

> 🎯 Ideal si te preguntas: _"¿Cómo escribo menos código?"_, _"¿Qué atajos me ahorran tiempo?"_
