# Programación Rápida

Bienvenidos al repositorio de comunidad para aprender, practicar y colaborar con ejercicios, apuntes y proyectos pequeños.

Este espacio está pensado para que el canal tenga:
- apuntes de referencia rápida
- ejercicios para practicar
- mini proyectos colaborativos
- una comunidad que comparte conocimiento y feedback

## Objetivo del repositorio

Crear un espacio abierto para:
- estudiar sintaxis de Java, JavaScript y C#
- resolver ejercicios paso a paso
- documentar temas clave
- trabajar en proyectos pequeños juntos
- aprender en comunidad

## Estructura del repositorio

- `apuntes/` - conceptos, referencias rápidas y notas de estudio
- `ejercicios/` - challenges y ejercicios por nivel
- `proyectos/` - mini proyectos grupales o individuales
- `comunidad/` - guías, reglas y recursos para la comunidad
- `.github/ISSUE_TEMPLATE/` - formularios para reportes y sugerencias

## Cómo colaborar

1. Haz fork del repositorio o clonalo localmente.
2. Crea una rama con un nombre claro: `feature/ejercicio-tabla`, `docs/apuntes-variables`.
3. Agrega contenido en la carpeta correcta.
4. Haz un Pull Request con una descripción clara.
5. Espera feedback y mejora.
