# Comunidad

Esta carpeta sirve como centro para guiar la participación de la comunidad del canal.

## Objetivos

- compartir dudas
- aprender juntos
- revisar ejercicios
- proponer proyectos
- mejorar el contenido del repositorio

## Dónde conversar

- GitHub Discussions: para dudas, ideas y propuestas
- Issues: para bugs o sugerencias de contenido
- Pull Requests: para aportar cambios y mejoras

## Recomendaciones

- Sé respetuoso con la comunidad
- Apoya a quienes están empezando
- Explica tus soluciones con claridad
- Haz preguntas concretas
- Comparte contenido útil y organizado

## Roadmap sugerido

- Semana 1: estructura base del repositorio
- Semana 2: ejercicios básicos
- Semana 3: proyectos pequeños
- Semana 4: comunidad activa y discusión
