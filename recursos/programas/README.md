# 🧰 Programas recomendados para programadores para programar XD

Aquí vive mi lista de **programas útiles** que voy descubriendo en el camino. No son extensiones de VS Code (eso está en otro lado), son **aplicaciones de escritorio** que te hacen la vida más fácil como programador. 🛠️

> 💡 **Regla de oro:** no instales todo de golpe. Instala lo que necesites cuando lo necesites. Tu PC te lo agradecerá. 😅

## 🔧 Git

**Control de versiones.** El programa más importante después del editor de código.

Con Git puedes guardar versiones de tu código, volver atrás si algo falla, y colaborar con otros programadores sin pisarse el trabajo. Es como una **máquina del tiempo para tu código**. ⏳

**Descargar:** [https://git-scm.com/](https://git-scm.com/)

**¿Por qué lo necesitas?** Porque ningún programador serio trabaja sin Git. Y GitHub, GitLab y Bitbucket dependen de él.

---

## 🐙 GitHub Desktop

**Git con interfaz gráfica.** Si la terminal te da miedo, esto te salva.

Te permite hacer commits, push, pull y ver el historial de cambios sin escribir ni un comando. Ideal cuando empiezas.

**Descargar:** [https://desktop.github.com/](https://desktop.github.com/)

**¿Cuándo usarlo?** Cuando trabajes con ramas y quieras ver visualmente qué está pasando. O cuando estés empezando con Git.

---

## 🖥️ Windows Terminal

**La terminal que Windows debió traer por defecto.**

Te permite tener varias terminales abiertas (PowerShell, CMD, WSL, Git Bash) en pestañas. Con temas, colores y una apariencia moderna. Ya no volverás a usar CMD viejo.

**Descargar:** [Microsoft Store](https://apps.microsoft.com/detail/9n0dx20hk701) (es gratis)

**¿Por qué lo recomiendo?** Porque una buena terminal te ahorra tiempo y dolores de cabeza.

---

## 📮 Postman

**Para probar APIs y solicitudes HTTP.**

Cuando empieces a trabajar con APIs (que será pronto), Postman te permite hacer peticiones GET, POST, PUT, DELETE y ver las respuestas sin escribir código.

**Descargar:** [https://www.postman.com/downloads/](https://www.postman.com/downloads/)

**¿Cuándo lo necesitas?** Cuando tu proyecto consuma o cree APIs. Antes no.

---

## 🐳 Docker Desktop

**Contenedores.** El estándar moderno para desplegar aplicaciones.

Permite empaquetar tu aplicación con todas sus dependencias para que corra igual en cualquier máquina. Suena a magia, pero es ingeniería. 🎩

**Descargar:** [https://www.docker.com/products/docker-desktop/](https://www.docker.com/products/docker-desktop/)

**¿Cuándo lo necesitas?** Cuando trabajes en proyectos con bases de datos, microservicios, o cuando quieras replicar entornos de producción.

---

## 🗄️ DBeaver

**Administrador de bases de datos universal.**

Un solo programa para conectarte a MySQL, PostgreSQL, SQLite, SQL Server, Oracle... y un largo etcétera. Con interfaz gráfica, editor SQL y visor de datos.

**Descargar:** [https://dbeaver.io/download/](https://dbeaver.io/download/)

**¿Cuándo lo necesitas?** Cuando empieces a trabajar con bases de datos reales. Antes no.

---

## 🗜️ 7-Zip

**Comprimir y descomprimir archivos.** El clásico.

Abre `.zip`, `.rar`, `.7z` y muchos formatos más. Es gratis y open source.

**Descargar:** [https://www.7-zip.org/](https://www.7-zip.org/)

**¿Por qué?** Porque tarde o temprano vas a necesitar descomprimir algo que Windows no puede abrir solo.

## 🎯 Orden recomendado de instalación

Si estás empezando de cero, este es el orden que yo seguiría:
Editor/IDE (VS Code, Visual Studio, IntelliJ)
↓

Git + GitHub Desktop
↓

Lenguaje que vas a usar (JDK, .NET SDK, Node.js)
↓

Windows Terminal
↓

Postman / DBeaver / Docker (solo cuando los necesites)

text

## 💡 Consejo final

**No instales todo de golpe.** Cada programa tiene su momento. Si no sabes qué es un contenedor, no instales Docker todavía. Si no sabes qué es una API, no instales Postman.

> 🎯 **Regla mental:** instala cuando lo necesites, no cuando lo veas en un video de YouTube.
