# Proyectos

Este directorio es para mini proyectos colaborativos, pequeños desafíos y experimentos de programación.

## Ideas de proyectos

- Calculadora con interfaz básica
- Agenda de contactos
- Sistema de notas
- Lista de tareas
- Juego de trivia
- Registro de estudiantes
- Mini blog de ejercicios

## Reglas para un proyecto

- Debe ser pequeño y claro
- Debe tener un objetivo definido
- Debe poder desarrollarse en grupo
- Debe incluir una breve documentación

## Formato sugerido

Cada proyecto puede llevar:
- `README.md`
- `src/` o `codigo/`
- `docs/` si aplica
- `ejemplos/` si hace falta
